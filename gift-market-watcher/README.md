# gift-market-watcher

Мониторинг TG-маркета NFT-подарков: листинги, смены цен, продажи, снятия.

## Шаг 0 — замер (`bench.py`)

Узнаём реальные цифры перед тем, как строить коллектор: сколько лотов, сколько запросов на цикл, где флуд-лимит.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # впиши TG_API_ID и TG_API_HASH
python bench.py             # первый запуск спросит номер и код — это вход в аккаунт
```

Флаги:
- `--delay 0` — без пауз, жёстче проверяем лимиты (запускай вторым прогоном);
- `--full-budget 0` — без полного обхода;
- `--limit 100` — размер страницы.

Результат — `bench_out/report.json` (цифры) и `bench_out/snapshot.json` (собранные лоты).

⚠️ Используй отдельный аккаунт, не основной. Файлы `.env` и `*.session` никому не отправляй — это доступ к аккаунту.
