## Что выяснено из документации Telegram (core.telegram.org)

- `payments.getResaleStarGifts flags:# sort_by_price:flags.1?true sort_by_num:flags.2?true for_craft:flags.4?true stars_only:flags.5?true attributes_hash:flags.0?long gift_id:long attributes:flags.3?Vector<StarGiftAttributeId> offset:string limit:int = payments.ResaleStarGifts`
  - Только для user-аккаунтов (не ботов).
  - **Без `sort_by_price`/`sort_by_num` сортировка — по времени последнего изменения цены, новые сверху.** Значит, первая страница = поток новых листингов и смен цен.
  - Пагинация через `offset`/`next_offset`; `counters` приходят только на первой странице.
- `payments.resaleStarGifts`: `count`, `gifts`, `next_offset`, `attributes`, `attributes_hash`, `counters`, `chats`, `users`.
- `starGift` (каталог из `payments.getStarGifts`): **`availability_resale`** = сколько гифтов коллекции сейчас на продаже, **`resell_min_stars`** = флор. Объём всего маркета узнаётся одним запросом.
- `starGiftUnique`: `owner_id` / `owner_name` / `owner_address`, `resell_amount: Vector<StarsAmount>` (звёзды и/или TON), `resale_ton_only`, `value_amount`/`value_usd_amount` (оценка). Поля «последняя продажа» нет, продажу вычисляем сами по смене владельца.
- Схема свежая (есть `crafted`, `burned`, `for_craft`). Если Telethon старый, в `bench.py` есть фолбэк на старое поле `resell_stars` и проверка наличия `GetResaleStarGiftsRequest`.

## Текущее состояние репо

- `bench.py` — замер: каталог коллекций → горячий скан (1 страница на коллекцию) → ограниченный полный обход (`--full-budget`, по умолчанию 300 запросов) → итог + `bench_out/report.json` и `bench_out/snapshot.json`. Ловит `FLOOD_WAIT` и логирует его.
- Флаги: `--delay` (по умолчанию 0.1 с), `--limit` (100), `--full-budget` (300; 0 = выкл).
- `requirements.txt`: telethon>=1.40, python-dotenv. `.env.example`: `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`.

## Как запустить (мак)

```
cd ~/Downloads && unzip -o gift-market-watcher.zip -d ~/PycharmProjects && cd ~/PycharmProjects/gift-market-watcher && python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && cp -n .env.example .env && open -e .env
```
Вписать ключи в `.env`, затем `python bench.py` и войти запасным аккаунтом.
